# 启真 Scientist

启真 Scientist 面向化学科研中的知识发现、实验设计、真实实验执行和结果评价，目标是构建一个能够持续从实验反馈中修正科研决策的 AI 科学家系统。项目将知识组织、可执行实验技能、自动评价和机理化风险识别连接成“知识启发—真机验证—评价反馈—自主迭代”的闭环。

## 仓库结构

- `idea_generation_scripts/`：使用 SciAtlas 生成和整理科研问题、跨学科灵感与实验计划的脚本及示例。
- `Mechanist/`：基于 Qoder 的 探索化学模型安全部署的AI 科学家研究框架，包含知识检索、实验流程和机理可解释性相关技能。
- `demo/idea_generation_demo/`：官方 125 道科学问题中 9 个化学问题的 SciAtlas 生成结果；其中“是否还能发现新的颜色颜料”是文档案例。
- `demo/labsafety-strict/`：实验计划较严格、能完整复现的化学模型安全部署结果。
- `demo/labsafety-loose/`：约束较宽松、便于用户按需求调整的化学模型安全部署结果，不保证每次都能逐项复现文档已有运行结果。
- `mechanist_frontend/`：项目展示前端。
- `qwen调用凭证/`：Qwen 调用凭证与用量记录。
- `tmp/`：本地参考项目和材料，已由 `.gitignore` 忽略，不上传到版本库。

## 作品信息

### （1）本作品针对的具体实验研究问题

面向化学科研中知识分散、实验空间大、试错成本高以及真实实验难以自主迭代的问题，研究如何使 AI 科学家贯通知识发现、方案设计、真机实验、科学评价与反馈进化，并依据真实实验结果持续修正科研决策。

### （2）本作品实际完成的核心方法

构建“启真 Scientist”知识—实验闭环智能系统，以 SciAtlas 组织跨学科科学知识，以 SkillNet+LabVLA 将实验方案转化为机械臂可执行技能，以 AutoSciRub 评价实验结果并反馈修正后续方案，同时引入机理可解释性开展部署前风险识别，形成“知识启发—真机验证—评价反馈—自主迭代”闭环。

### （3）最有代表性的结果 1（对象、口径、结果）

路径：`demo/idea_generation_demo/chemstry_question/01-新颜色颜料/`

面向官方 125 道科学问题中的“是否还能发现新的颜色颜料”，启真 Scientist 围绕 Mn/Cr 氧化物开展自主研究，从 4 篇种子论文扩展至 21 篇关联论文并构建证据图，识别关键科学缺口。系统依据评价反馈连续迭代 3 轮，将初始构想逐步修订为可检验的“潜在缺陷—光学代理模型”假设，并生成包含实验步骤、对照、评价及回退条件的研究计划，实现知识检索—假设生成—评价修订—实验设计的自主迭代。

### （4）最有代表性的结果 2（对象、口径、结果）

路径：当前 `demo/` 中尚未归档；

在 Suzuki–Miyaura 偶联反应条件优化中，与 Atlas 基线采用相同初始数据、候选空间和 20 轮实验预算；启真 Scientist 通过逐轮“实验—反馈—再决策”，第 11 轮即获得 96.30% 产率，较基线提前 5 轮达到 ≥95% 目标，所需实验减少 31.25%，并在 20 轮内发现 4 个 ≥95% 的高产率新条件，基线仅发现 1 个。

结果 2 的完整文件尚未归档到 `demo/`，当前先在本 README 记录已完成实验的对象、评价口径和结果指标。

### （5）最有代表性的结果 3（对象、口径、结果）

路径：`demo/labsafety-strict/`（严格复现版）和 `demo/labsafety-loose/`（宽松调整版）。

面向 AI 科学家进入真实化学实验室前的安全部署，本项目发现一种可绕过常规训练数据内容审查的隐蔽风险传播现象：使用经 Qwen3.8-Max 逐条筛选为安全的纯文本数据微调 Qwen3.5-9B 后，学生模型在多模态实验室安全任务中的不安全回答率仍达到 48.6%，显著高于未经微调的基线 20.3% 和安全数据对照组 18.3%，表明风险可在语义安全的数据中隐蔽传递并跨模态显现，为模型进入真实实验环境前的机理化风险检测提供了实验依据。
