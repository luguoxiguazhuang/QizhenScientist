# 启真 Scientist

启真 Scientist 面向化学科研中的知识发现、实验设计、真实实验执行和结果评价，目标是构建一个能够持续从实验反馈中修正科研决策的 AI 科学家系统。项目将知识组织、可执行实验技能、自动评价和机理化风险识别连接成“知识启发—真机验证—评价反馈—自主迭代”的闭环。

## 参赛作品名称

602406-浙江大学-王梦如-启真Scientist：面向化学的知识—实验闭环智能系统

## 仓库结构

- `01源代码/`：项目源代码。
  - `01源代码/Mechanist/`：基于 Qoder 的探索化学模型安全部署的 AI 科学家研究框架，包含知识检索、实验流程和机理可解释性相关技能。
  - `01源代码/idea_generation_scripts/`：使用 SciAtlas 生成和整理科研问题、跨学科灵感与实验计划的脚本。
- `02代表案例/`：项目代表性案例及其运行产物。
  - `02代表案例/idea_generation_demo/`：官方 125 道科学问题中 9 个化学问题的 SciAtlas 生成结果；其中“是否还能发现新的颜色颜料”是正文案例。
  - `02代表案例/labsafety/`：化学模型安全部署案例。
    - `02代表案例/labsafety/labsafety-strict/`：实验计划较严格、能完整复现的结果。
    - `02代表案例/labsafety/labsafety-loose/`：约束较宽松、便于用户按需求调整的结果，不保证每次都能逐项复现文档已有运行结果。
  - `02代表案例/experiment-iteration/`：Suzuki–Miyaura化学实验迭代案例，包含代码、输入数据、实验轨迹和复现说明。
- `03附录/03附录.pdf`：包含“Suzuki 反应闭环优化完整输出记录”和“有氧氧化反应闭环优化完整执行记录”。
